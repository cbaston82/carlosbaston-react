# Carlos Baston — Portfolio (v1)

My first portfolio website, originally built around 2014 and used professionally as a freelance developer. Migrated to React / Create React App.

## Tech Stack

- React 16
- Create React App (react-scripts 5)
- Sass
- Axios

## Running Locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
